# Providence 1.0.1

Providence now keeps selected libraries current automatically and makes local document search easier to browse, preview, and refine. The desktop interface uses Qt Quick/QML with themes and animation, and offline OCR brings printed text in scans and screenshots into search.

## Highlights

- Automatic file discovery and background indexing, with exclusions, processing states, pause/resume, and retry controls.
- Hybrid filename, exact-text, and semantic search using local models. Qwen3-Embedding-0.6B and the lighter MiniLM are available; model switching builds a separate compatible index.
- Offline OCR for scanned PDF pages and PNG/JPEG images, including cached text and PDF page references.
- A refreshed library with filters, sorting, breadcrumbs, resizable previews, keyboard navigation, light/dark/system themes, and reduced motion.
- Search starts only when you press Enter or Search. Typing, filter changes, and library updates do not launch AI searches.
- Stage progress, rotating helper messages, and optional folder, file-count, file-type, and date clues for searches still running after 20 seconds.

## Fixes and documentation

- Improved button contrast and hover text, bounded dropdowns, file-list spacing, section distinction, and preview padding.
- Added visible Locations & settings and Index health controls.
- Corrected Windows CI test-fixture placement: AppData/Temp is intentionally excluded from discovery, so tests now use a disposable workspace directory.
- Added public demo screenshots, a README cover, contributor instructions, and reproducible research results.
- Release tags run source validation; executable builds and publication require separate explicit workflow inputs. Future releases require a version-specific summary.

## Validation and limits

Source tests: **60 passed, 1 skipped** locally on Windows. The skipped symlink test needs permissions unavailable in the test environment. The corrected workflow still needs a successful GitHub-hosted run and a newly approved packaged-app check.

The synthetic retrieval evaluation uses 25 fictional files and 200 queries: Recall@5 was 96.5% for Qwen and 91.5% for MiniLM. These are smoke-test results, not guaranteed personal-library accuracy. See [validation methods and limitations](https://github.com/Totenem/Providence/blob/v1.0.1/docs/1.0.1-validation.md).

Progress percentages describe search stages, not confidence. Active model inference stops at a stage boundary rather than being forcibly interrupted. OCR quality varies with source images; handwriting and faithful table reconstruction are not promised. Indexes contain extracted text and are not encrypted.

Tray behavior, login startup, global shortcuts, an installer, signing, and document Q&A are outside this release. Version 1.1.0 remains future work.
