# Providence 1.0.2

Development draft. This version has not been packaged or published.

Providence adds read-only duplicate review, local visual image search, and content search for spreadsheets, slides, programming files, and common text formats.

## Highlights

- Duplicate review groups byte-identical copies by size and SHA-256, regardless of filename. Hard links are deduplicated, changed/unavailable files are skipped, and originals are never deleted or modified.
- Image search uses pinned local CLIP ViT-B/32 image/text embeddings. Update the image index explicitly, then submit an English description. Cached entries are reused and stale images are hidden; operations run in a cancellable worker.
- XLSX extraction includes sheet names and row labels with saved cell values. PPTX extraction includes slide text/tables and slide references. CSV/TSV, source code, JSON/YAML/TOML/XML, HTML, and other common text formats are searchable and previewable.
- WebP, BMP and first-frame TIFF join PNG/JPEG in the image/OCR path.
- A Next.js product website showcases the app, explains features, answers FAQs, and directs downloads to GitHub Releases. It runs locally through Docker; canonical URLs and indexing wait for a configured domain.

## Fixes and validation

- Newly supported files already in a library are queued for content extraction without requiring a file modification.
- The completed-search progress panel releases the result area, including in narrow windows.
- Failed or discarded searches clear the stuck “Searching…” state; failed searches also clear stale results.
- Search status names the submitted query, reports word/filename matches separately from potentially related files, and shows a clear no-results message in the QML result area.
- Document search prioritizes passages containing all useful remembered words, ignores common English filler words, and supports unambiguous one-edit spelling fallback against the local index.
- Explicit class/reference codes constrain retrieval: `1CS1` matches `1-CS1` but excludes other class codes. Result rows and previews explain filename, folder, passage and spelling evidence; stale entries outside the file catalog no longer inflate result counts.
- Source startup finds a previously downloaded MiniLM model in `build/model` when no model override or installed user model is present.
- New tool dialogs handle cancellation and closing without destroying a running worker. Skipped files show readable reasons.
- Download/build recipes include pinned, checksum-verified image weights and upstream attribution. Executable packaging remains subject to explicit release approval.

See [source validation and measured limits](../1.0.2-validation.md). Source checks do not replace portable EXE and native Windows release verification.

Final source suite on Windows: **99 passed, 1 skipped**. The skipped symlink test requires unavailable privileges. Light/dark/narrow library layouts and the new tool screenshots were visually reviewed using fictional paths.

Visual similarity is not confidence or proof of a match. The four-image synthetic colour smoke test is functional coverage, not a photo-search accuracy benchmark. English queries are supported initially; fine-grained objects, counting, no-match behavior, and representative photo-library scale need further evaluation. Image indexing is manual and must be refreshed after changes. XLSX does not calculate formulas; Office previews do not reproduce full application layouts.
