# Providence 1.0.3

Providence 1.0.3 adds durable favorites and saved searches, an optional local evidence reranker, and broader offline content support. Original files remain read-only and extraction and ranking stay local.

## Highlights

- Favorites can be added or removed from file results and filtered in the library.
- Saved searches retain their query, filters, and optional clues for reuse.
- An optional deterministic local evidence reranker adds filename and passage word overlap after retrieval. It downloads no model and performs no cloud inference.
- EPUB, OpenDocument text/spreadsheet/presentation files, Jupyter notebooks, and legacy `.doc`, `.xls`, and `.ppt` files are supported. Legacy Office extraction uses an installed local LibreOffice converter.
- HEIC and HEIF images are supported through the bundled `pillow-heif` decoder and remain available to preview, OCR, and visual image search.

## Validation and limits

- Source suite: **101 passed, 1 skipped** on Windows; the skipped symlink test requires permissions unavailable in the validation environment.
- Focused post-release-wiring checks: **35 passed, 1 skipped**.
- EPUB/OpenDocument/notebook extraction, persistent favorites, saved-search storage, QML controls, and UI behavior are covered by tests.
- Legacy Office support requires LibreOffice to be installed locally. XLSX still uses saved values without formula calculation; OpenDocument extraction is text-focused; notebooks include cell source and text outputs.
- HEIC/HEIF decoding depends on the bundled decoder and remains subject to the existing image size/resource limits.
- The optional reranker is deterministic lexical evidence, not a trained cross-encoder. It makes no accuracy guarantee.
